# นักอ่านตัวจิ๋ว อ่านเองได้

เกมฝึกอ่านภาษาไทยแบบ PWA สำหรับเด็กประถม ออกแบบให้ใช้ได้บน iPhone, iPad และคอมพิวเตอร์

## กิจกรรมในเกม
- ห้องเรียนพยัญชนะไทย ก-ฮ จำนวน 44 ตัว
- สนามฝึกอ่านพยางค์ คำศัพท์ และประโยค พร้อมคำถามแบบเลือกตอบ
- คลังคำศัพท์พร้อมภาพประกอบ
- นิทานภาษาไทยพร้อมเสียงอ่านจากระบบ Text-to-Speech ของอุปกรณ์
- ฝึกเขียนตัวอักษรด้วยนิ้ว
- สะสมดาว เหรียญรางวัล และบันทึกความก้าวหน้าในอุปกรณ์

## ติดตั้งบน iPad
1. เปิดเว็บไซต์เกมผ่าน Safari บน iPad (ต้องเป็น HTTPS)
2. แตะปุ่ม Share
3. เลือก Add to Home Screen
4. ตั้งชื่อ “นักอ่านตัวจิ๋ว” แล้วแตะ Add
5. เปิดเกมจากไอคอนบนหน้าจอ Home

## เล่นออฟไลน์
เปิดเกมออนไลน์ให้โหลดครบหนึ่งครั้งก่อน จากนั้น Service Worker จะเก็บไฟล์หลักและภาพประกอบไว้ในเครื่อง การใช้งานเสียงอ่านขึ้นอยู่กับเสียงภาษาไทยที่ติดตั้งและรองรับใน iPad; เสียงสังเคราะห์อาจไม่พร้อมใช้งานในบางอุปกรณ์หรือขณะออฟไลน์

## เผยแพร่
เปิด GitHub Pages ใน Settings > Pages แล้วเลือก Deploy from a branch, branch `main`, folder `/ (root)` จากนั้นรอให้ GitHub Pages เผยแพร่เว็บไซต์ผ่าน HTTPS

> ความก้าวหน้าจะถูกเก็บไว้ในอุปกรณ์/เบราว์เซอร์เครื่องนั้น ยังไม่มีระบบบัญชีเพื่อซิงก์ข้ามอุปกรณ์ และเกมไม่ได้ประเมินการอ่านผ่านไมโครโฟน
