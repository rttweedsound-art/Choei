# นักอ่านตัวจิ๋ว อ่านเองได้

PWA เกมฝึกอ่านภาษาไทยสำหรับนักเรียน ป.1–3 พร้อมบทเรียนพยัญชนะ สระ ผสมเสียง คำ ประโยค และนิทานสั้น

- ปุ่มขนาดใหญ่ เหมาะกับ iPad
- เสียงอ่านภาษาไทย เมื่อเบราว์เซอร์รองรับ
- สะสมดาวและบันทึกความก้าวหน้าในอุปกรณ์
- ใช้งานออฟไลน์ได้หลังเปิดเว็บไซต์ครั้งแรก

> แอปนี้ไม่มีการประเมินการอ่านผ่านไมโครโฟน
